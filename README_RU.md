# Навигатор по простым числам

Учебный алгоритмический проект для поиска и просмотра простых чисел в окрестности заданного большого целого числа с использованием `BigInteger` и варианта сильного теста Миллера на псевдопростоту.

Проект объединяет алгоритм проверки чисел с интерфейсом Windows Forms: приложение показывает страницу 10×10 из ближайших простых чисел и позволяет переходить к соседним страницам.

## Стек

C# · .NET · `BigInteger` · модульное возведение в степень · проверка на простоту · Windows Forms

## Алгоритм

Основная реализация:

1. представляет `n - 1` в виде `2^s · t`, где `t` нечётно;
2. проверяет фиксированный набор малых простых оснований через `BigInteger.ModPow`;
3. выполняет повторные возведения в квадрат по модулю в сильном тесте Миллера;
4. ищет простые числа слева и справа от заданного значения, пока не будет набрана нужная страница;
5. поддерживает последовательное перемещение между соседними страницами простых чисел.

Интерфейс ограничивает входные значения диапазоном до `10^36`.

## Структура репозитория

- `MillersDeterminateAlgorythm/Algorythm.cs` — проверка на простоту и генерация страниц простых чисел;
- `PrimeNumbersList/` — Windows Forms приложение и таблица 10×10;
- `PrimeNumbersList.sln` — решение Visual Studio.

## Замечание о корректности

Репозиторий сохраняет исходную учебную реализацию. Фиксированный набор оснований в тесте Миллера и проверка точной степени через числа с плавающей точкой являются частью исторического кода. Для production-реализации следует использовать формально обоснованный набор свидетелей для точного диапазона входных чисел и целочисленную проверку точной степени.

## Контекст

Ценность проекта прежде всего алгоритмическая: модульная арифметика, большие целые числа, проверка на простоту и построение интерактивного приложения вокруг алгоритма. Проект не предназначен для замены современной криптографической библиотеки по теории чисел.
